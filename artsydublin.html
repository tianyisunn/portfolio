01
Overview

A platform built for Dublin's living art scene

Artsy Dublin is a web platform for discovering local performance and arts events in Dublin — music, theatre, film, ballet and beyond — tailored to your interests. It also connects you with people who share those interests, so you never have to go alone.

The project sits at the intersection of event discovery, personalised recommendation, and lightweight social connection — three things existing platforms handle poorly when combined.

Platform overview — homepage mockup
02
The Problem

Existing platforms aren't built for art people

Platforms like Eventbrite have reasonable event categorisation — but they're general-purpose. Anyone can create an event and tag it however they like, leading to unreliable, polluted category data.

①
Inaccurate tagging — user-generated events frequently carry wrong or misleading category labels.
②
Weak recommendation algorithms — existing platforms don't build a nuanced interest profile; suggestions feel random.
③
No spontaneous social layer — social features focus on long-term groups, not lightweight, event-specific buddy-finding.

"I want to find someone to go to a jazz night with — not join a Facebook group about jazz."

03
The Solution

Curated sources + social layer + personal diary

Rather than relying on user-generated tags, Artsy Dublin sources event data directly from reputable venues and institutions — concert halls, cinemas, galleries — keeping quality high and noise low.

A

Event Buddy Matching

See who else is going to an event and send a lightweight "join me" request. No long-term commitment required until you want one.

B

Art Event Diary

Log events you've attended. Add a short reflection, a rating, a photo. Your diary becomes both a keepsake and the basis for your recommendation profile.

C

Tailored "For You" Feed

Recommendations built from your interest profile, diary history, and what your connections are attending — not generic "popular in Dublin" filler.

D

Playful Events

User-created "crazy event" ideas — PowerPoint nights on art topics, debate clubs, collaborative viewing parties.

Core features mapped to user needs

Design

Warm, tactile, cultural — not another cold tech app

The visual direction was deliberate: Dublin's art scene feels warm, textured, analogue. We committed to cream and deep brown — like aged paper, like a theatre programme, like the wood panelling of a jazz venue.

06
Technical Stack

Backend-heavy, React front-end — integration in progress

This is primarily a backend project. The core technical challenges live in data sourcing, recommendation logic, and user state management — not the UI layer.

Event Sourcing

API integration pulling event data directly from verified Dublin venues and cultural institutions — bypassing user-generated noise.

Recommendation Engine

Algorithm built on user interest profiles, diary history, and social connections. Personalisation deepens with use.

Front-end

React — component-driven, responsive. Currently being built independently from backend; integration phase next.

Content Management

User profiles, diary entries, event logs, social connections — all managed through a structured backend data layer.
